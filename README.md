# Spring Boot Demo

Java / Spring Bootを使用して作成したREST APIの学習・開発プロジェクトです。

## 概要

Spring Bootを使用して、REST APIの基本的な実装を学習しています。

GET / POST API、DTO、JSON、レスポンス、設定値の取得などを実装しています。

## 使用技術

- Java
- Spring Boot
- Maven
- Git
- GitHub

## 実装内容

- GET API
- POST API
- DTOを使用したリクエスト・レスポンス
- JSONによるデータの受け渡し
- application.propertiesを使用した設定値の取得

## 開発環境

- Windows
- IntelliJ IDEA
- Java
- Spring Boot
- Maven
